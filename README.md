# 🃏 나래 짝꿍 카드 — 화폐 짝 맞추기 게임

### ▶ [바로 시작하기: https://khs84.github.io/narae-pair/](https://khs84.github.io/narae-pair/)

5학년 수학 **Lesson 13 화폐** 학습지(2~15차시)를 바탕으로 만든 짝 맞추기 놀이입니다.
돈 카드의 지폐·동전을 세어 보고, 값이 같은 금액 카드나 물건 카드를 찾아 짝을 짓습니다.
전자칠판 터치에 맞춰 만들었고, 모든 안내는 음성으로 들려줍니다.
(같은 학습지로 만든 가게놀이 게임: [나래 마트](https://khs84.github.io/narae-mart/))

## 단계

| 단계 | 짝 맞추기 | 연결 차시 | 쓰는 돈 |
|---|---|---|---|
| 1단계 | 돈 카드 ↔ 몇천 원 금액 카드 | 2~7차시 | 천 원, 오천 원 |
| 2단계 | 돈 카드 ↔ 몇천 몇백 원 금액 카드 | 8~11차시 | 천 원, 오천 원, 백 원 (설정에서 오백 원 추가) |
| 3단계 | 돈 카드 ↔ 같은 값의 물건 카드 | 12~15차시 | 천 원, 오천 원, 백 원 |

- **짝꿍 수**: 3쌍(카드 6장) · 4쌍(8장) · 6쌍(12장)
- **카드 놓기**
  - 👀 **펼쳐 놓기 (쉬움)**: 모든 카드가 보입니다. 두 장을 차례로 누릅니다.
  - 🔄 **뒤집어 놓기 (기억 놀이)**: 처음에 카드를 잠깐 보여 준 뒤 뒤집습니다. 두 장씩 뒤집어 짝을 찾습니다. 막히면 **잠깐 보기** 버튼으로 다시 볼 수 있습니다.

## 놀이 방법
1. 카드를 한 장 누르면 노란 테두리가 생기고 음성이 나옵니다. 금액 카드는 "삼천 이백 원", 물건 카드는 "라면은 삼천 사백 원이에요"처럼 읽어 줍니다.
2. 짝이라고 생각하는 카드를 한 장 더 누릅니다.
3. 값이 같으면 ✔ 번호와 도장 ⭐을 받고, 돈 카드의 돈을 하나씩 짚으며 "천, 이천, 이천 백… 모두 이천 백 원이에요" 하고 함께 셉니다.
4. 값이 다르면 "값이 달라요"라고 알려 주고 카드가 원래대로 돌아갑니다. 두 번 연속 틀리면 **함께 세어 보기**를 권합니다.
   이 버튼을 누르면 선택한 돈 카드를 함께 셉니다.
5. 짝을 모두 찾으면 **짝꿍 앨범**이 나옵니다.

## 전자칠판에서 쓰기
- **인터넷 없이 실행**: 폴더를 USB로 옮긴 뒤 `index.html`을 더블클릭합니다. 설치할 것은 없습니다.
- **전체 화면**: 오른쪽 위 ⛶ 버튼을 누르거나 `F11` 키를 누릅니다.
- 모든 버튼은 손가락 터치 크기이고, 끌기 없이 **누르기만** 하면 됩니다.
- 화면 크기에 맞춰 카드와 돈 그림 크기가 자동으로 바뀝니다 (FHD·4K, 가로·세로 모두 지원).

## 음성
- **모든 문장을 자연스러운 AI 음성(Microsoft SunHi Natural)으로 미리 녹음해 두었습니다** (`assets/audio/`, 340개).
  나래 마트와 같은 목소리이며, 인터넷이 없어도 재생됩니다.
- 금액 읽기("삼천 이백 원"), 함께 세기("천, 이천…"), 합계("모두 ○○ 원이에요")는 100원부터 9,900원까지 모두 녹음되어 있습니다.
- ⚙️ 설정: 말하기 속도, 짝을 찾으면 함께 세기 켜기/끄기, 500원 동전 넣기, 효과음.

### 음성 다시 만들기 / 바꾸기
```powershell
pip install edge-tts
python tools/generate_audio.py --reset                       # 기존 녹음 지우기
python tools/generate_audio.py                               # SunHi(여성, 기본)
python tools/generate_audio.py --voice ko-KR-InJoonNeural    # 남성 목소리
```

## 물건·가격·문장 바꾸기
`data/game-data.js`에서 물건 이름, 이모지, 가격, 읽어 줄 문장(`say`)과 안내 문장(`lines`)을 고칠 수 있습니다.
문장을 고친 뒤에는 `python tools/generate_audio.py --only <id>`로 그 문장만 다시 녹음합니다.

## 폴더 구조
```
index.html              화면 구성
css/style.css           디자인 (터치·화면 크기 대응, 카드 뒤집기)
js/voice.js             음성 엔진 (녹음 파일 → 브라우저 자연 음성 순)
js/money.js             지폐·동전 그림, 금액 읽기(3200 → 삼천 이백 원)
js/game.js              게임 진행
data/game-data.js       물건·가격·음성 문장
assets/audio/           녹음된 음성 파일
tools/generate_audio.py 녹음 음성 만들기
```

> 지폐·동전은 실제 화폐를 본뜨지 않은 학습용 그림입니다.
